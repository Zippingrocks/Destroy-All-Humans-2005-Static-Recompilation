# Security Policy

## Supported versions

The project is in active development and has not published a stable release.
Security fixes are applied to the current development branch. Old local builds
are not supported.

## Reporting a vulnerability

Do not publish a security vulnerability, malicious game image, exploit or
sensitive log in a public issue. Use GitHub's private vulnerability reporting
feature when it is available for this repository. Otherwise contact the
repository owner privately through the contact method on their GitHub profile.

Include the affected commit, impact, reproduction conditions and the smallest
safe proof needed to understand the problem. Do not include copyrighted game
data or private information.

Ordinary crashes, graphical errors and gameplay differences belong in the
public bug-report form.
