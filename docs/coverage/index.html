What the colors mean

Recovered means a dedicated callback translation exists. Observed seed means runtime evidence caused the address to be retained for dispatch. Auto translated means the static translator emitted and dispatches the function. Stubbed means a known target still has placeholder behavior. A parity-note marker means the address appears in captured comparison evidence; it does not by itself claim pixel accuracy.
