What the colors mean

Code regions preserve the original executable's address neighborhoods. Implementation status gathers functions by the kind of recompilation evidence we have. Function size only removes grouping for a raw size comparison. Recovered means a dedicated callback translation exists; observed seed means runtime evidence retained the address for dispatch; auto translated means the static translator emitted and dispatches the function; stubbed means a known target still has placeholder behavior. A white corner marker links the address to parity notes.
