# Community Code of Conduct

This project welcomes people who want to study, preserve and improve the
original *Destroy All Humans!* experience.

Be respectful, specific and patient. Discuss evidence and code rather than the
person presenting it. Welcome good-faith bug reports and questions from people
with different experience levels. Do not harass, threaten, discriminate
against, impersonate or expose private information about another person.

Project spaces must not be used to distribute copyrighted game data, malware,
credentials or personal information. Repeated disruption, abuse or deliberate
misrepresentation may result in comments being removed or participation being
restricted.

Report conduct concerns privately through the repository owner's GitHub
profile. Security vulnerabilities should use the process in `SECURITY.md`.
