# X8 sampled-alpha correction, 2026-09-26

The native Pox screen developed red glow after the correct retail reverse
subtract blend equation was implemented. The defect was in texture-view alpha:
Xbox X8R8G8B8 samples alpha as one, while the native RGBA-backed render-target
SRV exposed stored alpha. Low alpha incorrectly discarded threshold-pass
pixels, leaving earlier red CRT pixels to be blurred and added to the scene.

Local xemu source proves both swizzled format `0x07` and linear format `0x1E`
use RGB8 in `Repos/xemu/hw/xbox/nv2a/pgraph/gl/constants.h` and alpha-ONE swizzles
in `pgraph/vk/constants.h`. Native combiner generation now applies that semantic
immediately after each enabled X8 sample, before dependent texture reads. The
per-stage mask participates in shader caching and resets on each state upload.
A8 formats retain stored alpha. Both PGRAPH combiner paths set the mask from
the sampled formats; render-target writes and the correct blend equation remain
unchanged. The separate fixed-function movie fallback is outside this fix.

## Regression checks

Run from an x64 VS developer shell:

```powershell
node tools/test_x8_alpha.mjs
node tools/test_dependent.mjs
node tools/test_blend_equation.mjs
```

All pass. The X8 suite checks 112 offscreen WARP channels using production
combiner decoding, generated HLSL and shader caching, including the captured
threshold combiner, A8/X8 switching, four stages, and dependent-AR ordering.
Its old-stored-alpha control fails with stale red 204 instead of expected 64.
The texture fixture also exercises A8→X8→A8 mask routing through actual PGRAPH
postprocess submission. Existing coverage remains 24 texture checks, 4096
dependent lookup channels, and 112 blend channels, with their negative controls.

This proves a specific defect and its correction. Complete pixel equality,
animation phase, frame sequences and timing remain unverified. GPU readback,
RenderDoc and debugger-instrumented runs are not timing parity evidence. Menu
work is pinned; the active investigation proceeds to Farm loading/gameplay.
