# Changelog

All notable public-facing project changes will be recorded here once versioned
releases begin.

The project is currently in an unversioned development phase. Git history and
the issue tracker remain the authoritative record of individual changes.

## Unreleased

### Available

- Native Windows x86-64 boot through the original title screen and front end.
- Profile creation, save selection and Bink movie playback.
- D3D11 rendering through a DAH-specific XboxRecomp runtime.
- XInput controller support and a development keyboard fallback.
- Crash logging, event tracing and retail-parity investigation tools.
- A public recompilation coverage dashboard.

### In progress

- Full-campaign stability and mission validation.
- Rendering, effects, visibility, animation and transition parity.
- Audio completion and synchronization.
- Repeatable unattended regression coverage.
- Public release packaging.
