# Accessibility

Accessibility support is currently limited because the project is still
restoring the original game's behavior.

## Current support

- XInput-compatible controllers use the game's original control model.
- A development keyboard fallback covers movement, menu navigation and the
  primary Xbox buttons.
- Windowed operation is available during development.

## Known limitations

- Keyboard and mouse input is not yet a complete replacement for a controller.
- Controls cannot yet be rebound through a player-facing interface.
- The project does not currently add subtitle, color, text-size or assistance
  options beyond those supplied by the original game.
- Screen-reader support has not been implemented for the game interface.

Accessibility problems can be reported with the GitHub bug-report form. State
the barrier, the input or display setup, and the result that would make the
game usable. Do not include private medical information.

Accuracy remains the current milestone, but accessibility work that can be
implemented without destabilizing retail behavior is welcome.
